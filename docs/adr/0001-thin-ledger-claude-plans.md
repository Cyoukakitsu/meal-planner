# 服务端只做账本，由 Claude 负责想菜

MCP 服务端只保存库存、计划和个人档案，并保证扣减、期限和状态的正确性；不内置菜谱库，也不调用任何 LLM。排菜、估算用量、识别小票都由手机上的 Claude 完成。

Claude 本来就会做菜，缺的只是用户的具体约束，这些放在个人档案里即可。内置菜谱库或再接一个 LLM 只会增加费用、故障点和维护量。

## Considered Options

- 服务端内置菜谱库或推荐逻辑：否决，原因同上，且菜谱库不了解用户的一锅一铲约束。
- 安装第三方菜谱 Skill：否决，同样不了解约束，且手机端 Skill 支持不稳定。

## Consequences

- 以后想加“推荐菜”功能，应该改个人档案或 Claude 的提示，而不是在服务端加推荐逻辑。
- 服务端必须严格校验 Claude 传来的数据，例如扣减不能超出库存 20% 以上。

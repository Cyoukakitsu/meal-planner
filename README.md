# meal-planner

一个给自己用的料理规划 MCP 服务。买完菜后，把食材（文字或小票）发给手机上的 Claude，它会帮你入库、按库存排接下来几天的饭，并在备菜、做饭时自动扣减库存。

## 它能做什么

- 记录食材的数量、存放方式（冷藏、冷冻、常温）和消费期限，快到期时提醒。
- 工作日午餐按便当安排（前一晚备菜、早上 15 到 20 分钟做完），周末和日本祝日按在家做饭安排。
- 根据库存量决定计划天数，食材不够时会明确告知。

## 设计

服务端只做“库存和计划的账本”，想菜的事交给 Claude。技术栈：Hono、Cloudflare Workers、Neon Postgres。
